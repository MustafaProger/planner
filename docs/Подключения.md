## Повторная диагностика

Руководитель может нажать «Источники данных → Проверить соединения». Выполняются только фиксированные HTTPS GET с ограничением времени, без паролей и без перехода по редиректам. HTTP-ответ означает лишь доступность страницы, а не успешную авторизацию. Результат сохраняется с временем проверки. Кнопка «Обновить из исходных Excel» обновляет только Excel-снимок и так и подписана.
