## ТрансТрейд

Пользователь подтвердил продукт https://tt-net.ru/ . Официальная страница [модулей](https://transoft.ru/modules/) описывает API получения заказов и клиентов. [Документация API](https://tt-ok.ru/data/api_doc/) требует API KEY и api_user_id. В предоставленном файле есть обычные логин/пароль, но нет этих API-реквизитов. Необходимо подтвердить подключение модуля и получить выданные провайдером реквизиты; входной адрес конкретной облачной базы также пока не установлен. API для записи в систему не нужен.

Известная документированная операция чтения — POST GetOrders с диапазоном FromOrderDate/ToOrderDate и подписью запроса. Пример ответа включает адреса, логиста, машины, водителей и суммы, но поле нормативного километража в опубликованном примере отсутствует: перед окончательным отображением нужно проверить реальный ответ. Коннектор без реального ответа не выдаётся за готовую синхронизацию.

## Нефтьмагистраль

Предоставлен https://pws.neftm.ru/pws/login.do . Браузер показал ERR_TIMED_OUT. Одна проверка заголовков вернула HTTP 200; последующая загрузка страницы входа снова завершилась таймаутом TLS. ## Повторная диагностика

Руководитель может нажать «Источники данных → Проверить соединения». Выполняются только фиксированные HTTPS GET с ограничением времени, без паролей и без перехода по редиректам. HTTP-ответ означает лишь доступность страницы, а не успешную авторизацию. Результат сохраняется с временем проверки. Кнопка «Обновить из исходных Excel» обновляет только Excel-снимок и так и подписана.
