# Текущее состояние планировщика — 2 ноября 2026

Рабочий адрес: **[charterstats.ru](https://charterstats.ru/)**. Этот документ — актуальная точка входа; исторические отчеты описывают свои даты и этапы.

## Область приемки и версии

Согласованный объем — опубликованный аналитический планировщик с подключенными заявками, спутником и топливными источниками, планированием, статусами и доступными расчетами. **Автоматический километраж TransTrade отложен пользователем до отдельного этапа.** Отсутствующие реальные факты и неподтвержденные бизнес-правила не заменяются догадками.

Базовый SHA приложения: `677636891dcfc13109d0467f9b3448af3a709daa` (`Publish VPS planner and redesign sign-in screen`). Ветка — `codex/logistics-analytics`, upstream — `origin/codex/logistics-analytics`. Нынешний цикл изменяет документацию и проверку интерфейса; принятый экран входа, роли, расчеты и стили сохраняются. Итоговый commit определяется историей Git этого документа; SHA самого нового commit нельзя достоверно записать в него до создания.

Рабочие web и worker находятся на VPS. Локальный рабочий runtime остановлен после переноса; локальный `data/` — архив, не сегодняшний серверный snapshot. Данные и действия тестовых пользователей изолированы от VPS. Новые локальные изменения и push **не означают их развертывания на VPS**; повторная публикация в этом цикле не выполняется.

## Проверки и вердикт

**Техническая приемка согласованного объема пройдена.** Нового воспроизводимого дефекта расчетов, сохранности или интерфейса в проверенных сценариях не обнаружено. Основные механизмы готовы для работы по доступным данным; полная экономика и точная телеметрия водителя не аттестованы без реальных фактов. Неопределенные R28–R30 остаются явно ограниченными, автоматический КМ — отложенным.

Свежие результаты 2 ноября:

- **396 Python-тестов прошли**, включая **7 проверок реальных книг**, без skip; 3 предупреждения openpyxl относятся к оформлению при чтении. Отдельный временный `FLEET_DATA`, scheduler отключен. [Команда, время и хеши Python](acceptance-20261102/checks.json).
- **45 JavaScript-тестов прошли**, **2/2 sidebar-сценария** прошли из чистого временного checkout без личного `NODE_PATH`. Строго сохранена прокрутка после navigation/rerender/Back/Forward. Ошибочный selector завершился за 3,587 с, сброс прокрутки пойман за 0,644 с; свои браузеры закрыты. [Протокол](acceptance-20261102/sidebar.md).
- Живая приемка на синтетической базе: **1440×1000 и 390×844**, настоящий вход/backend, 3 роли, доступные 3 200 ₽ и 31 ч при неизвестном КМ, 4 записи / 2 рейса / 1 рабочий день, средние/группы/CSV/детали, обе сверки, шесть столбцов дельт, статусы без заказа, план на 2027 год и несколько назначений, формы при обновлении. JavaScript-ошибок и внешних запросов — 0. Содержательные проверки чисел дельт, тарифов/истории, 27 ч, конфликтов удаления/полноты и no-op связаны с конкретными тестами в [матрице](acceptance-20261102/customer-matrix.md).
- **VPS 14:29:56 МСК:** web/worker active/enabled, свежий heartbeat; все 4 current/history success, `pending_days=0`; обычная авторизация и GET основных API — 200, анонимные данные — 401. **35 файлов приложения на диске совпадают с `6776368`**. Загруженный в память Python bytecode отдельно не аттестован; SQLite прочитана согласованной транзакцией, JSON — независимо при работающем worker. Это наблюдение состояния, не полный восстановимый backup. [Протокол и границы](acceptance-20261102/production.md).

Текущая приватная очередь VPS: **91 спорное назначение** (88 неназначенных, 2 строки возможного дубля, 1 review), **25 карт / 1 034 непривязанные топливные операции**, **18 отдельных записей на проверку**. Реальных смен, привязок карт, дополнительных расходов, подтверждений полноты и наблюдений КМ — 0. Отдельные 1 987 сочетаний водитель–машина–дата служат запросами к журналу; это **не число подтвержденных смен**. Очередь с ID и недостающими полями находится только в `.local/acceptance-20261102/production-facts.json` (0600).

Прежняя внешняя длительность ошибочного sidebar-запуска около 563,7 с ретроспективно не объяснена. Новый runner задает отдельные пределы и проверяет cleanup при искусственной ошибке; это доказательство ограниченного нового запуска, а не установленная причина прежней задержки.

## Оставшиеся входы и ограничения

| Область | Точный следующий вход | Куда вводить / граница |
|---|---|---|
| Автоматический КМ ТТ | Отдельное решение о продолжении, подтвержденный источник сохраненного КМ и контракт автоматического получения | **Отложено**, не обязательный блокер нынешнего commit. Готовый CSV/XLSX preview/confirm — ручное дополнение, не подключенная автоматика. |
| Реальные смены | Водитель, машина, начало/конец с timezone и подтверждающий журнал | «Контроль → Километраж и смены». Суточный спутниковый агрегат нельзя точно разделить на части смены без измерений нужного интервала. |
| Карты | Поставщик, карта, машина, даты начала/конца использования, подтверждающий источник | «Карты и автомобили». Непривязанные покупки не распределяются по похожим названиям. |
| Спорные назначения | Решение по каждому ID: водитель/машина/дата; отдельная смена или основание отмены дубля | Планировщик и справочники; приватная очередь содержит конкретные записи. |
| Расходы и простои | Дата, машина, категория, сумма, основание; отдельные причины статуса машины/водителя | «Расходы» и «Календарь → Статус / простой»; результат виден в отчете «Работа и простои». Топливную покупку не дублировать расходом; отсутствие ввода не означает ноль. |
| Полнота | Ответственный проверяет реальный период и подтверждает его актуальный preview | «Полнота периодов». Успех API и пустая очередь загрузки не доказывают бизнес-полноту. |
| Предупреждения | Явно выбранные канал и получатель, затем настройка и отдельная проверка доставки | Механизм проверен с fake transport. Реальных сообщений в этом цикле нет. |
| Неопределенные правила R28–R30 | Надежный ключ маршрута; правило частичного дня/приоритета статусов; налоговая модель | Агрегатное сравнение, независимые события и исходные суммы сохранены. Чистая прибыль и незаказанные правила не заявлены. |

Резервные копии VPS находятся на том же сервере; внешний backup/retention и полный reboot не проверялись заново. Абсолютная полнота API поставщиков и неизменная доступность в будущем не следуют из успешного снимка.

## Сохранность и воспроизведение

Перед изменениями сохранена приватная резервная копия 296 файлов проекта и baseline. Рабочие бизнес-данные, доступы, роли и исходные книги не изменяются; новый рабочий scheduler локально не запускается. Приватные очереди/снимки, `data/`, доступы и старые исследовательские артефакты не добавляются автоматически в commit. Точечный список файлов, проверка diff/секретов и сохранности фиксируются в [протоколе изменения](acceptance-20261102/change-review.json).

Команды воспроизведения: [README](../README.md). Браузер sidebar использует перехваченный `fleet.test`; пользовательская приемка — временную базу, отключенный scheduler, тестовые роли и отдельный localhost. Эти результаты отдельно от read-only состояния рабочей системы.
