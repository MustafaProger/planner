## Последняя функциональная доработка

После приемки 14:37 пользователь поручил реализовать недостающий функционал, исключив разбор спорных рабочих записей. Повторная проверка сквозного сценария R09/R19/R20/R22 обнаружила, что правильные агрегаты еще не обеспечивали полный переход от итога к исходным записям. Исправлены конкретные пользовательские действия:

| Было | Теперь |
|---|---|
| Строки «Сводки плана» не раскрывались | Нажатие открывает назначения выбранной группы с датами, маршрутом, сохраненными суммами и источником. Записи, не вошедшие в итог, показаны отдельно с причиной. |
| Строки «План–факта» не раскрывались | Открываются отдельно плановые назначения и фактические заявки-рейсы, все шесть показателей и причины недоступных дельт. Начисления вынесены отдельно; попарное соответствие рейсов не выдумывается. |
| Отклонение в сверке/обзоре открывало только заявки | Карточка показывает использованные спутниковые показатели и источник каждого значения; исходные интервалы Excel видны отдельно. Замененный API пробег не прибавляется повторно, доступные часы Excel сохраняются. |
| Для проверки дня приходилось заново искать машину и месяц | Из карточки можно открыть нужный день календаря. Back/Forward восстанавливают машину, период и группировку; день без заказов сохраняет контекст и не объявляется простоем. |

Детали и итог используют одинаковый серверный отбор и один снимок данных. Полнота сохраняет исходную область отчета, не пересчитывается только по нажатой группе. Есть загрузка, ошибка с повтором, защита запоздалых ответов, управление с клавиатуры и сохранение существующих прав. Рабочие записи при доработке не менялись.
