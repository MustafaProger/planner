Старые версии не вытесняют новые; конфликт одного timestamp блокирует пакет. Повтор preview проверяется внутри write transaction.
- Подтверждённые интервалы имеют явный часовой пояс и длительность timestamps. Измерение распределяется целиком единственному покрывающему интервалу; пересечения остаются без распределения. Денежные отчёты не зависят от смен.
- Coverage учитывает содержательные поля/ID и исключает технические timestamps, revision, комментарий. Отпечаток повторно проверяется под SQLite write lock; перемещение даты меняет оба периода. Дополнение км входит в dataset до проверки полноты.

- Средние делят соответствующие исходные суммы на числа записей/рейсов; сумма всех категорий на рейс показана отдельно. При неизвестных составляющих основные показатели остаются null. Текущая принадлежность явно отделена от исторической.

## Найденные замечания

1. **P2, `app/static/evidence.js`, `mileageForm`** — поздний preview старой формы мог записать результат в новую форму через глобальный `#mileagePreview`. Воспроизведено изолированным VM: открыть форму → запрос preview → закрыть/открыть новую → завершить старый запрос; `old_request_overwrote_new_form=true`. При редактировании во время запроса сбрасывался `prepared`, но поздний ответ опять показывал подтверждение. Нужны identity/generation guards и FormData snapshot. Исправлено агентом evidence: identity/generation guards, локальные DOM ссылки, неизменяемый FormData snapshot, блокировка полей во время commit. Новая реализация просмотрена повторно; независимый запуск `node --test tests/test_evidence_ui.cjs` — **10 passed**, включая оба воспроизведения и поздний confirm.
2. **P2, `app/importer.py`, `resolve_sources`** — повреждённая низкоприоритетная локальная конфигурация мешала валидному `FLEET_EXCEL_DIR`. Воспроизведено в temp directory: две существующие книги + валидный env directory + невалидный JSON config → отказ чтения config. Рекомендовано ленивое чтение config только при недостающих explicit/env путях. Исправлено главным агентом: resolver теперь сначала разрешает explicit/env и читает config только при недостающих путях. Исправление и регрессия `test_environment_does_not_read_unused_broken_local_config` просмотрены; главный агент подтвердил 5 portable tests passed.
3. **P2, выбор периода evidence** — страница использовала `from/to`, но не имела формы дат; интервалы вне унаследованного месяца нельзя было открыть непосредственно. По отдельному поручению главного агента reporting включил evidence в датированные страницы: только два input date, без неработающих фильтров машины/водителя. Добавлен тест реальной общей разметки `reportFilterFields` на произвольный период 2027 года. Главный агент проверяет живой переход периода в browser V01.

Все три обнаруженных кодовых замечания исправлены. Полная браузерная и итоговая сквозная приёмка остаётся отдельной проверкой V01.
