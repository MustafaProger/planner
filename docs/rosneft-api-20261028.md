## Что доступно

Страница http://127.0.0.1:8765/integrations/rosneft показывает руководителю:

- выбор периода до 31 дня и кнопку «Обновить из Роснефти»;
- операции, включая обслуживание, возвраты, пополнения и списания со счёта;
- товар, количество, цену, сумму, скидку, сумму после скидки, адрес АЗС, ID операции и ссылку возврата;
- текущие примечания и статусы карт;
- поиск, сортировку и CSV.

Данные сохраняются локально; обновление целиком заменяет отображаемый период, без накопления дублей. Ошибка сети, запрет доступа или некорректный ответ сохраняют предыдущую загрузку. Автоматическое фоновое обновление не включено. Операции пока не включены в расходы рейсов: текущее примечание карты не доказывает историческую связь карты с машиной.

## Контракт API и хранение

Использована [официальная инструкция WebAPI](https://lk.rn-card.ru/documents/WebAPI-EMV-v2.pdf), версия 2.0.0.42, включая изменение 19.10.2026. Локальная копия PDF и извлечённый текст находятся в исключённом из Git `work/`.

Разрешены только GET `https://lkapi.rn-card.ru/api/emv/v1/GetCardsByContract` и GET `/api/emv/v2/GetOperByContract`. Логин передаётся как параметр `u`, пароль — только в заголовке `RnCard-Identity-Account-Pass` в Base64 согласно документации. Проверка TLS включена; редиректы с реквизитами запрещены; сырые ошибки запросов не выводятся.

Код договора установлен по странице «Дополнительная информация о договоре». В закрытом `data/rosneft-credentials.json` сохранены только необходимые реквизиты Роснефти; права 0600. Исходный Excel не изменён и целиком не скопирован. Файл исключён из Git. При следующей смене пароля нужно обновить серверный файл реквизитов.

Снимок: `data/rosneft-transactions.json`, атомарная запись с правами 0600. Десятичные суммы сохраняются строками без потери точности. `NetSum = Sum - DSum` для обслуживания/возвратов; возвраты вычитаются в итогах. Время операции сохраняется по часовому поясу терминала, без ложного преобразования в МСК. По инструкции провайдера операции могут поступать с задержкой до двух часов.
