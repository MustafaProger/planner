1. Откройте [личный кабинет РН-Карт](https://lk.rn-card.ru/Users/ReLogin.aspx). Используйте актуальные реквизиты клиента. В исходном Excel логин находится в B23, пароль — в B24. Снимите «Запомнить меня». Если вход снова отклонён, переходите к восстановлению.
2. Откройте [«Забыли пароль?»](https://lk.rn-card.ru/Account/PasswordReminder). Укажите логин, почту, привязанную к кабинету, и код с картинки. Нажмите «Сбросить пароль» и выполните действия из письма.
3. Если логин неизвестен, отметьте «Я не помню логин»: сайт отправит список логинов на привязанную почту. Затем повторите восстановление с нужным логином. Если доступа к почте нет, обратитесь к своему менеджеру или на 8 800 200 10 70; по FAQ понадобится официальное письмо организации с номером договора и новым адресом почты.
4. После успешного входа откройте «Инструкции» → инструкцию по WebAPI. Этот раздел указан в [официальном FAQ](https://lk.rn-card.ru/Faq). Сохраните документацию для настройки интеграции.
5. Уточните у менеджера РН-Карт, подключён ли API для договора. Если нет — направьте заявку в свободной форме сотруднику отдела продаж/сопровождения. По опубликованной [тарифной политике](https://lk.rn-card.ru/EMVTOLsrv) доступ к API предоставляется безвозмездно. Способ авторизации и выданные реквизиты нужно подтвердить у менеджера; обычный вход в кабинет сам по себе не доказывает доступность API.
