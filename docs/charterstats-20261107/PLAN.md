# CharterStats — локальная переделка, 7 ноября 2026

## Источники и решения до реализации

Изучен общий чат https://chatgpt.com/share/6aede73e-4d80-83ed-98ac-aa1125101ac6, включая первоначальные замечания, последующие уточнения пользователя и редакцию CS-001–CS-027. Скриншоты задают отдельные распределения заявок по клиентам и дней по статусам, а также сравнительную диаграмму выручки и выплат.

Референсы: Stageshow 1.1.0, `chart-scrub` (скопирован в frontend/src/references), `craft.md`; https://ui.shadcn.com/examples/dashboard; https://www.tremor.so/. Композиция: светлый рабочий интерфейс, узкая навигация, один основной график, спокойные карточки, синий для выручки, зелёный для результата, янтарный для проверки. Stageshow предоставляет реальные компоненты Button/Card/Badge. Его сценарные анимации и декоративные курсоры не подходят рабочему интерфейсу: графики и фильтры реагируют на пользователя.

## Размещение

- Обзор: основные KPI, динамика выручки и выплат, распределение календарных дней, клиенты, очередь проверки.
- Автопарк / Водители / Клиенты: профильные таблицы, рейтинг и детализация исходных записей.
- Сравнение: объекты за период и динамика по периодам, общий выбор автомобилей/водителей/исполнителей/типов/клиентов.
- Календарь: основные статусы и дополнительные события, переходящие рейсы, пустые дни, переход к существующим формам редактирования.
- Контроль: единый список отклонений с комментарием и историей проверки.
- ГСМ: заправки, нормативы, отдельно фактический расход; отсутствие связи карты не означает нулевой расход.
- Маршруты: предварительный расчёт двух вариантов по имеющимся тарифам, явные ограничения.
- Справочники: подтверждённая принадлежность и отдельная группа без принадлежности.

## Границы источников

Изменения локальные. Архивный data/ не является актуальной серверной базой. Предпросмотр использует отдельную SQLite-копию; реквизиты провайдеров не копируются, scheduler отключён. Дата финансового учёта сохраняет существующую дату начала заявки: дата завершения в общем чате была только предложением, не подтверждённым решением. Рабочие дни учитываются по всему интервалу. Справочник компаний не доказывает импорт принадлежности из ТТ. Отдельная выплата водителю не выводится из WorkerSum. Суточный спутник не является точным пробегом интервала рейса. 1С, ФинТабло и новые запросы к провайдерам не подключаются в этой локальной переделке.
