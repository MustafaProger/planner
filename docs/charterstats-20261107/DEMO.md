## Что посмотреть

1. **Ноябрь · обзор** — заполненные KPI, график, семь календарных состояний, клиенты и контроль.
2. **Динамика за год** — сразу открывает сравнение за январь–ноябрь с 11 месячными столбцами.
3. **Календарь / А101АА777 / 14–15 ноября** — переходящий рейс; **18 ноября** — работа и дополнительный ремонт.
4. **Отклонения** — движение без заявки, работа ниже порога, перепробег, пропуск спутника, моточасы без движения, повторная заправка и карта без привязки. Проверка части записей уже содержит учебные комментарии.
5. **ГСМ** — заполненные расходы, объёмы, средняя цена и нормы; заправленный объём остаётся отдельным от расхода.
6. **Автопарк** — собственные и привлечённые машины, рейтинг, оценка выручки простоя. **Водители / Клиенты** — денежные показатели и подробные записи.
7. **Справочники** — группы исполнителей и транспорта; намеренно оставлены неизвестная принадлежность и тип для демонстрации контроля качества.
8. **Экономика маршрутов** — сравнение двух вымышленных тарифных сценариев. Назначения автоматически не меняются.

## Изоляция и возврат

Демо хранится в `.local/charterstats-demo-20261107`, исходный локальный снимок — `.local/charterstats-20261107`. Дополнительно сделана SQLite-копия `before-demo.sqlite` в папке исходного локального снимка. Каталоги и операции реальной базы в демо не переносились: скопированы только существующие учётные записи для привычного входа. Ключи провайдеров не копировались, scheduler отключён. Демоисточник включается только при сочетании `FLEET_DEMO=1` и `FLEET_LOCAL_PREVIEW=1`.

Создание: `npm run demo:seed`. Запуск: `npm run preview:demo`. Возврат к локальному снимку: остановить демопроцесс на порту 8776 и запустить `npm run preview:charter`. Повторное создание не перезаписывает уже существующие изменения демобазы. Это не публикация на сервер.

## Проверка

Два теста проверяют состав, признаки вымышленных записей, переходящий рейс, повторный запуск без потери изменений и обязательность обоих флагов деморежима. Три теста API CharterStats и 18 расчётных тестов проходят. Сборка успешна.

Браузером проверены вход с прежней учётной записью, баннер, ноябрьские показатели, годовая динамика (11 месяцев), суммы заправок и открытие переходящего рейса. Ноябрь: 190 рабочих авто-дней из 300; сумма семи основных статусов — 300, без повторного счёта дополнительных событий. Есть все девять реализованных видов сигналов.

При проверке заполненного календаря исправлен счётчик дополнительных событий: основной ручной статус дня больше не попадает в него. Ремонт после рейса по-прежнему считается дополнительным событием. Все 11 новых страниц открыты с баннером демо и без сообщений об ошибках.
