# CharterStats: результат локальной переделки

7 ноября 2026. Локальный адрес: http://127.0.0.1:8776/charter/overview.

Это работающий интерфейс существующего Flask-приложения, а не отдельный макет с вымышленными цифрами. React, Stageshow Button/Card/Badge, Recharts. Новый обзор открывается с корня приложения. Старые формы планирования, исходных заявок и редактирования сохранены и доступны по ссылкам. Публикации, обновления производственной базы и новых запросов к провайдерам в этой работе не было.

## Источники и локальные данные

Прочитан [общий чат](https://chatgpt.com/share/6aede73e-4d80-83ed-98ac-aa1125101ac6), требования CS-001–CS-027 и два приложенных скриншота. Расположение дашбордов выбрано до реализации: [PLAN.md](PLAN.md). Примеры чата не используются как реальные показатели компании.

Предпросмотр использует отдельную SQLite-копию в `.local/charterstats-20261107`. Скопированы только сохранённые факты; ключи и сессии провайдеров не копировались. Scheduler отключён, сервер слушает 127.0.0.1. Изменения статусов, принадлежности, норм и проверки отклонений в этом предпросмотре сохраняются в копии.

Учтена параллельная задача пользователя «Удалить функции Excel локально»: записи Excel исключены из рабочих данных, файловая выгрузка также удалена. Эти изменения сохранены. Поэтому пункт об экспорте из исходного v1.0 сейчас не реализуется. Подробности отдельной задачи: [API-only](../api-only-20261107.md).

В доступном снимке есть заявки ТТ, но нет спутниковых API-показаний. Километраж ТТ, зарплата отдельным полем и дата обновления источника не подставляются из других величин. Интерфейс показывает отсутствие данных. Тарифы маршрутов — сохранённый справочник, актуальность тарифов не подтверждалась обращением к ТТ.

## Покрытие требований

«Реализовано локально» означает доступное поведение и выполненные проверки этой работы, не приёмку компанией. Полная дорожная карта не объявляется завершённой.

| Требование | Результат и оставшиеся границы |
|---|---|
| CS-001 | Иерархия и выбор, отдельные поля заявки, собственные/привлечённые/неизвестные. Связь из справочника или ручного подтверждения; импорт справочника принадлежности ТТ требует отдельной проверки. Исполнитель заявки не становится автоматически владельцем автомобиля. |
| CS-002 | Множественный выбор типов, группировка, исключение категорий выплат из физических типов. Неопределённые типы видны; нет нового импорта справочника ТТ. |
| CS-003 | Список отсутствующих связей и типов, заявок без машины/водителя, ошибочных дат/интервалов, повторных ID. Не все смысловые дубли и неизвестные категории начислений распознаются автоматически. |
| CS-004 | Поиск, несколько исполнителей/машин/водителей/типов/клиентов/статусов, выбор всех и очистка, счётчик, сохранение между вкладками. Суточный спутник не приписывается водителю/клиенту; такие срезы помечаются как недоступные. |
| CS-005 | День, неделя, месяц, квартал, год, диапазон до 730 дней; предыдущий аналогичный период; месячная навигация календаря. |
| CS-006 | Пустой день автоматически «Не заполнено»; ручной «Без заявки» отдельно. Состав календаря основан на текущем справочнике, без истории включения автомобиля в парк. |
| CS-007 | Число дней/проценты, список дат, карточка дня, назначенные водители, события, добавление статуса. Редактирование прежних статусов доступно переходом в существующий журнал. |
| CS-008 | Работа имеет приоритет; ремонт остаётся дополнительным событием. Разные нерабочие статусы одного дня отмечаются конфликтом, а не считаются двумя днями. |
| CS-009 | Одна заявка, рабочие даты по интервалу, километры один раз. Входящий рейс из прошлого месяца учитывается в рабочих днях текущего без повторного начисления денег. Точная спутниковая сверка рейса требует интервальных данных. |
| CS-010 | Обзор и детализация доступных показателей; пропуски показаны явно. Не все показатели можно получить из текущего снимка API. |
| CS-011 | Выручка, выплаты, разница, доли; раздельные группы принадлежности. Зарплата своего водителя не выводится из общей выплаты исполнителю. Состав расходов явно ограничен. |

| CS-022 | Экран сценария с явными предупреждениями. Автоматического поиска неэффективных назначений и проверки доступности машин/водителей пока нет. |
| CS-023 | Совокупный результат обоих назначений и изменение в рублях/процентах. Неизвестный тариф запрещает итог. Дополнительный пробег, время и ограничения требуют данных; назначения не меняются. |

## Правила расчёта

- Финансовая дата сохранена как дата начала заявки. Дата завершения была предложением в общем чате, а не подтверждённым решением пользователя.
- Нет двойного вычитания выплат. Результат не назван чистой прибылью.
- Пропуск суммы отличается от нуля. Неполная финансовая сумма не выдаётся за полный итог. Спутниковая сумма относится только к доступным показаниям.
- Процент отклонения — относительно ТТ. При нуле процент отсутствует.
- Рабочий день по парку — автомобиль/дата, а не просто дата для всей компании. У водителя — уникальная дата назначения.
- Для точного перепробега по имеющемуся суточному спутнику допускается только одна заявка с точно совпадающими суточными границами; обычные рейсы не сопоставляются с целыми сутками без оговорок.
- Экономика маршрутов — предварительный сценарий по сохранённым тарифам, не подтверждённое фактическое назначение.
