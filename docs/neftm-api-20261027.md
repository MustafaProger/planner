# Нефтьмагистраль · API транзакций

27 октября 2026 подключён документированный API чтения транзакций. Авторизация успешна, реальные данные получены и сохранены. Записи у поставщика не изменяются.

## Использование

Руководитель открывает «Подключения → Нефтьмагистраль» (`/integrations/neftm`), выбирает даты в карточке «Нефтьмагистраль · транзакции» и нажимает «Обновить из Нефтьмагистрали». Доступны поиск, сортировка и CSV. Загрузка ограничена 93 календарными днями за запрос. Планировщик автоматического обновления не включён; время последней загрузки показано в МСК.

В таблице сохраняются типы операций: обслуживание (11), возврат на счёт (24), остальные типы отображаются исходным кодом. Количество и сумма не складываются без учёта услуги и валюты. Название держателя не превращается автоматически в госномер; включение в экономику рейсов требует отдельного сопоставления карт и машин.

## Хранение и обработка

- Ключ хранится в `data/neftm-api.key` с правами 0600, каталог data исключён из Git. Ключ не возвращается браузеру и не попадает в аудит.
- Запрос: POST `https://pws.neftm.ru/public-api/transactions.do`, JSON с token/dateFrom/dateTo/format=XML. Документация поставщика: https://pws.neftm.ru/pws/data/Transactions-API.pdf.
- Только HTTPS, проверка сертификата включена, редиректы с ключом запрещены, ответ ограничен 20 МБ. Ошибки отображаются без содержимого запроса или ответа поставщика.
- XML проверяется до сохранения. DTD/ENTITY не принимаются; обязательные даты и числа проверяются. Денежные значения, номера карт и исходные строки сохраняются без округления.
- Последний успешный снимок находится в `data/neftm-transactions.json`, права 0600. Запись атомарная. Обновление заменяет снимок выбранного периода, не добавляет его повторно. У API нет ID транзакции: одинаковые операции внутри ответа не удаляются.
- При ошибке API предыдущий снимок остаётся доступным. Одновременные обновления блокируются. Чтение таблицы и запуск обновления разрешены только admin; POST защищён CSRF.

## Проверено

- Реальный API за 01–31 августа 2026: HTTP 200, 140 транзакций по шести картам; 139 с кодом 11 и одна с кодом 24.
- Повторное обновление через кнопку в Chrome: снова 140 строк; статус «API подключён», время последней загрузки обновилось, ошибок JavaScript нет.
- 35 pytest: существующие расчёты и права, XML/точность/возвраты, отсутствие удвоения, сохранность снимка при 401/302/500/таймауте/неверном XML, запрет для наблюдателя, CSRF.
- Ключ не менялся. Регулярное обновление и сопоставление карт автомобилям не настраивались.
