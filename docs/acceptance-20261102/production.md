## Граница этой проверки

Разрешённая обычная авторизация и последующие GET не изменяли бизнес-данные. Не выполнялись `/sync`, принудительный refresh, импорт, отправка предупреждений, смена доступов, DNS, deployment или reboot. Production-браузерный обход всех ролей и мутационные проверки здесь не проводились — для них используется изоляция, а не рабочая БД. SSH-ключ временного транспорта удалён после операции; новых постоянных файлов с ключами/сессиями не создано.

Локальная папка `data/` после cutover остаётся архивом. Ни числа из неё, ни исторические 28/15 дней очереди не подставлены вместо нового VPS-среза. Пустая очередь выше относится только к указанному времени.
