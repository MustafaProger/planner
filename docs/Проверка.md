## Автоматические проверки

14 проверок pytest: суммы и количество записей, спутниковая сводка, планы, исключение начислений из загрузки, фильтр машины, уникальные рабочие дни, null вместо отсутствующего спутника, объединение статусов, длительности больше суток, нормализация госномера, аутентификация/CSRF/Host, запрет чтения локальных секретов по HTTP, роли и назначенные машины, повторный ввод/мягкое удаление, планирование по дням недели, повторный импорт и сохранение ручных записей, обе сводки выплат «Чартера».

Предупреждения openpyxl об ограниченной поддержке срезов/рисунков относятся к возможному сохранению книги. Исходные книги не сохраняются и не изменяются; используется только чтение.

## Браузер

Проверено в локальном браузере: вход руководителя, фильтр машины, детализация, календарь, формы статуса и назначения, сохранение двух плановых дней и расчёт ставки, календарное представление плана, план–факт на выбранном интервале, сверка км/часов, источники и повторный импорт. Проверки записи проводились на отдельном экземпляре и базе work/ui-test на порту 8766; рабочая база на 8765 не содержит тестовых ручных записей. Настольная компоновка проверена. Запрошенное через браузерный инструмент изменение размера не применилось (фактическая ширина оставалась 4363 px), поэтому мобильная компоновка реализована CSS, но браузером на узком экране не подтверждена.

## Ограничения

Внешняя синхронизация не завершена: нет сетевой доступности кабинетов с этого компьютера; у ТТ дополнительно отсутствуют выданные API KEY/api_user_id. Пароли не проверены. Подробности — Подключения.md. Топливные операции не загружены, чистая прибыль не рассчитывается. Приложение доступно локально, наружу не опубликовано. Ввод/редактирование справочников пока через импорт книг; ручное добавление реализовано для статусов и назначений. Масштабирование на многопользовательский сервер потребует отдельного размещения, HTTPS и настройки резервирования.
