## Расчёты

- Выручка и выплаты — суммы числовых значений исходных записей; дополнительный налоговый коэффициент не применяется. Контрольные значения по машинам совпали с кэшированной сводной.
- 1 130 строк ТТ: 996 записей с номером заказа и 134 строки простоев без номера. Денежные записи разделены по исходному типу: 815 рейсов, 90 удержаний/штрафов, 64 погрузки, 19 сервисных начислений, 8 доплат. Название категории не заменяет проверку спорной записи.
- Часы = полная разница окончания и начала, включая сутки. Часы, пробег, рабочие дни и среднее время рейса в основной статистике считаются только по категории «Рейс». Все исходные часы и км по начислениям доступны в ТрансТрейде.
- Дни = число разных дат работы, а не количество записей. Средние часы = часы рейсов / число рейсов. ₽/час и ₽/км используют часы/км ТТ; спутниковые показатели стоят отдельно.
- Спутник сопоставляется через пары объект–госномер из справочника; длительность берётся из столбца «Продолжительность». Дата группировки — дата начала, без искусственного деления ночного рейса. Нет строки — null/«—», а не ноль. Сверка: ТТ минус спутник.
- В сводке по водителю, клиенту, типу или паре водитель–машина спутник не распределяется: данных о фактических сменах водителя в спутниковой выгрузке нет.
- В «Маршруты Почта»: ставка = часы × клиентский тариф; выплата партнёру = часы × тариф партнёра; зарплата своего водителя — отдельная ставка. Исключения с нулевой ставкой сохранены из кэшированных значений. Назначение хранит ставку на момент создания.
- Планы импортированы за июль и сентябрь; факт — за август. При отсутствии одного источника отклонение не рассчитывается. Доплаты/удержания видны в статистике, план–факт сравнивает рейсы.
- Статусы объединяются по дате, типу сущности, сущности и причине, с сохранением происхождения. Повтор одинаковой записи не создаётся.
- Водитель не закреплён за машиной навсегда: связь хранится в конкретной заявке/назначении. Имена партнёров в столбце автомобилей не превращаются в вымышленные госномера.

## Ограничения исходных данных

На листе «Анализ» 56 ошибок #REF! в GETPIVOTDATA. Встроенная бинарная модель Power Pivot не является исполняемым движком приложения: метрики восстановлены из исходных таблиц, сверены по доступным сводным; вся DAX-модель не переносилась. Поле «Руб/час» старой сводки не совпадает с делением на полную длительность и заменено явной формулой.

Реквизиты налогового расчёта на листе «Рент» не содержат оператора между стоимостью и коэффициентами 1,05/1,22. Повторно менять уже импортированные денежные значения на их основе нельзя.

В исходных справочниках есть варианты написания фамилий и служебные значения (например «НЕТ МАРШ»). Автоматического слияния разных имён нет. Вопросы качества, включая строки без автомобиля и длительности свыше суток, перечисляются в источниках данных. Адресов и имён логистов в этой Excel-выгрузке нет.
