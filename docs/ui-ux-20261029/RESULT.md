## Изменения

- Общая система форм, кнопок, заголовков, таблиц, пустых состояний и диалогов. Убраны вложенные белые панели фильтров и несогласованные отступы.
- Все фактические таблицы находятся в «Данных». «Настройки → Подключения» показывают статус каждого источника и ведут к его таблице. Старые прямые ссылки сохранены.
- «Контроль → Качество данных» показывает тип замечания, влияние на расчёт, следующий шаг и конкретные записи. Отсутствующий в API километраж выделен как ограничение источника. Исторические замечания Excel сгруппированы и свёрнуты.
- Пустые полнота периодов, карты и расходы содержат описание и понятное действие. Никакие бизнес-связи не выдуманы и не заполнены автоматически.
- Календарь предварительных назначений поддерживает строки по маршрутам и по автомобилям — два представления прежних Excel-сводных.
- «Помощь → Как пользоваться» содержит карту Excel → приложение и два отдельных сценария: план против фактических заявок; заявки против спутника. Подробное руководство: [Руководство-заказчика.md](../Руководство-заказчика.md).
- Общая кнопка обновления и серверный цикл 300 секунд. Текущий месяц для ТТ и топливных источников, последние завершённые сутки для спутниковой истории. Состояния, ошибки и успешное время видны по каждому источнику.
- История топлива читается по выбранному периоду, поэтому автообновление другого месяца не заменяет просматриваемые строки. При вводе в форму обновление экрана откладывается.

## Существенные пределы

В API ТТ отсутствует актуальный километраж; «—» не становится нулём. Привязки топливных карт, дополнительные расходы и подтверждения полноты пока пусты. Полная чистая прибыль, распределение спутника по водителям и буквальное исполнение всей DAX-модели не заявляются. Все исходные рабочие записи сохранены; источники и производные представления сведены в проверяемую карту.
