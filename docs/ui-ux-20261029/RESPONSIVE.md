# UI/UX и адаптивность — 29 октября 2026

Проверено 27 страниц приложения: 23 пункта меню и 4 отдельные страницы состояния подключений. Каждая открыта в реальном Chrome через `cua_repl` на ширинах **320, 390, 768 и 1440 CSS px**. Итог: **108 сочетаний страницы и ширины — без горизонтального переполнения документа**. Доказательства: [responsive-checks.json](responsive-checks.json).

## Что проверено и исправлено

- Единую систему отступов, панелей, фильтров, полей и кнопок применили ко всем страницам. Убраны повторные переопределения layout в CSS и вложенные белые панели у табличных toolbar.
- Поля и основные кнопки имеют минимальную высоту 44 px. Закрытие карточки, поиск, навигация и чекбоксы доступны на мобильном экране.
- При ширине 320 px формы, группы действий, карточки итогов и подключения становятся в одну колонку. Настольные карточки четырёх подключений расположены в сетке 2 × 2.
- Широкие таблицы прокручиваются внутри собственного контейнера; документ остаётся шириной экрана. На телефоне первая колонка обычных таблиц больше не закрывает большую часть доступной области.
- У диалогов ограничена ширина экрана и доступна вертикальная прокрутка. Содержимое и поля не обрезаются.
- Исправлена подсветка месяца: плавающая подложка после переноса кнопок могла оказываться под другим месяцем. Теперь выделение относится непосредственно к выбранной кнопке.
- При проверке 768 px обнаружено переполнение страницы спутника: чекбокс повторной загрузки наследовал `width: 100%`. У него установлена собственная ширина 20 px; повторная проверка пройдена.
- Сохранена прокрутка длинного меню при переходах, поддержаны видимый focus и reduced motion.

## Сценарии на 320 px

- Открыты и закрыты без сохранения формы привязки топливной карты, подтверждения полноты, назначения маршрута и добавления автомобиля. Поля и кнопки помещаются в диалог; ширина прокрутки формы равна её клиентской ширине.
- В планировщике включён календарь маршрутов: таблица ограничена контейнером.
- В качестве данных выбрана категория отсутствующих API-показателей: список показывает 1–100 из 1034. Кнопка «Следующие» переводит на 101–200, ширина документа остаётся 320 px.
- Проверены пустые состояния полноты, привязок карт и расходов: есть причина отсутствия записей и понятное действие.
- В подключениях проверены переходы к данным и состоянию каждого из четырёх источников.

Историческая синхронизация, изменение учётных данных и сохранение деловых записей в ходе UI-аудита не выполнялись. Функциональные проверки серверного обновления описаны отдельно в тестах проекта. Последний просмотр журнала ошибок вкладки после перезапуска сервера — без сообщений.

Доказательства интерактивных сценариев: [interaction-checks.json](interaction-checks.json).

- На 390 px меню сохранило прокрутку после перехода «Импорт Excel» → «Доступы и журнал» и повторного открытия: 817 → 817 px.
- После перехода в статистику поиск «А314» показал 1 из 58 строк, очистка вернула 58 из 58. Сортировка выручки переключилась между ascending и descending с соответствующим порядком значений.
- Клавиша ArrowRight прокрутила таблицу на 40 px; подсказка о горизонтальной прокрутке видна. Таблица шириной 2757 px осталась внутри контейнера 330 px, ширина документа — 390 px.
- Итоговое руководство содержит 20 листов Excel. Его таблица повторно проверена на всех четырёх ширинах: перенос длинных описаний работает, на телефоне прокручивается контейнер, переполнения документа нет.
- Финальный снимок подключений содержит реальную успешную проверку всех четырёх источников от 29.10.2026, 10:36 МСК. Временные размеры окна сброшены, тестовая вкладка закрыта.
