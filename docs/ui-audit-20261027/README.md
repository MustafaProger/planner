# Исправления интерфейса и аудит — 27 октября 2026

Локальный сервис: http://127.0.0.1:8765/analytics/statistics.

## Изменения

- Ограничена ширина рабочей области; широкие таблицы прокручиваются внутри своего контейнера. Убрано перекрытие содержимого верхней панелью при прокрутке.
- Поля дат, месяцев, текста, пароля, поиска, одиночные select и кнопки используют общий радиус 999px.
- Формы открываются компактной карточкой справа, с анимацией выезда, размытым фоном, крестиком, Escape и отменой. Изучена открытая карточка добавления водителя на сервере образца; данные образца не изменялись. Высота коротких форм определяется содержимым.
- В календаре и планировщике создание отделено от параметров отображения; экспорт планировщика находится у таблицы результатов. Действия фильтра расположены отдельной строкой.
- Справочники используют верхний слой Popover API, ограничиваются краями экрана и открываются вверх при нехватке места снизу. Следующая карточка больше не перекрывает список машин.
- Каждый из десяти разделов получил отдельный путь /analytics/…, /planning/… или /data/…. Ссылки поддерживают новую вкладку, прямой вход, перезагрузку и историю браузера. Переходы внутри приложения сохраняют анимации.

- 15 pytest: расчёты Excel, фильтрация, права, CSRF, дедупликация, ручные статусы и планы, повторный импорт, отдельные пути страниц и недоступность произвольных файлов. Изменения данных в тестах выполнялись в отдельной временной базе.
- node --check app/static/main.js и git diff --check: успешно.
- Chrome: все 10 разделов на ширинах 1470, 1024, 390 px. На всех 30 комбинациях ширина документа равна ширине viewport; ошибок в toast не было.
- История назад/вперёд, перезагрузка прямой ссылки, переключение месяцев, фильтр А314МА95 (25 рейсов, 698 290 ₽), сброс фильтров, поиск таблицы (1 из 57), сортировка и открытие детализации с клавиатуры.
- Календарное и табличное представления планировщика; открытие форм статуса и назначения, отмена и Escape.
- Поиск машины, выбор стрелками/Enter, множественный выбор и Escape. Проверка elementFromPoint подтвердила, что открытый список находится над соседними карточками и над формой.

- Вычисленный радиус всех видимых полей статистики: 999px.
