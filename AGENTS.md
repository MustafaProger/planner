# Документация проекта

Актуальное описание проекта находится в папке [`project/`](project/). Перед изменением кода прочитайте относящиеся к задаче файлы:

- [`project/design.md`](project/design.md) — визуальные правила, адаптивность и поведение интерфейса.
- [`project/structure.md`](project/structure.md) — каталоги, компоненты, данные и размещение на сервере.
- [`project/functionality.md`](project/functionality.md) — пользовательские возможности, источники и границы расчётов.
- [`project/status.md`](project/status.md) — текущее состояние, незавершённые и следующие задачи; правила обновления статуса.

Каждый файл посвящён только своей теме. После изменения поведения обновляйте соответствующий файл, а после завершения задачи — `project/status.md`.
