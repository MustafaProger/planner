# Функционал

Приложение объединяет заявки TransTrade, спутниковые показания и топливные операции Нефтьмагистрали и Роснефти. Доступны обзор, автопарк, водители, клиенты, сравнение, календарь, планировщик, отклонения, ГСМ, экономика маршрутов, исходные данные, справочники, подключения, настройки и пользователи. Права ограничивают просмотр и изменения по роли и доступным автомобилям.

Планировщик хранит назначения водителя, автомобиля и маршрута с тарифом на дату. Отчёты показывают агрегаты и исходные записи; из деталей можно перейти к дню календаря. Ручные статусы, справочники и комментарии проверки сохраняются отдельно от данных поставщиков. Обновление API выполняет отдельный worker; состояние источников и ошибки показываются в интерфейсе.

Основная форма планировщика сохраняет назначение со статусом «Назначен» автоматически. Для сохранения нужны маршрут, автомобиль или партнёр и водитель.

Переключатели «День», «Неделя», «Месяц», «Квартал» и «Год» строят диапазон вокруг одной и той же опорной даты и сохраняют фильтры. Ручной выбор даты в диапазоне задаёт новую опорную дату. Календарная неделя идёт с понедельника по воскресенье и может захватывать соседний год. Опорная дата сохраняется при перезагрузке вкладки.

Локальная ветка использует только API для рабочих данных: импорт книг, файлов километража и файловая выгрузка убраны из пользовательского пути. Исторические строки SQLite сохранены, но не подставляются вместо отсутствующего текущего API факта. Пробег TransTrade через действующий API не подтверждён; неизвестное значение остаётся неизвестным. Суточный спутниковый пробег не приписывается произвольной заявке, водителю или клиенту. Заправка не равна расходу топлива; результат по доступным затратам не называется чистой прибылью.

Опубликованный на VPS release может отличаться от локальной ветки. Перед утверждением, что функция доступна пользователям, проверяйте текущий release и живой сценарий на сайте.

На странице подключений локальная копия показывает сохранённые отметки с датами, а демонстрация помечает все карточки как демонстрационные. Кнопки проверки сети и обновления данных показаны руководителю в рабочем режиме.
