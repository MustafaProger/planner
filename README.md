# Логистика — аналитика автопарка

Локальное веб-приложение на русском языке. Рабочая база с редактируемыми справочниками, планами, заявками, статусами и расходами; первоначально заполнена существующими Excel-книгами. Для ежедневного ввода Excel не нужен. Не требует облачной публикации. Artel-CRM не используется и не изменяется.

## Запуск

```sh
cd '/Users/mustafa/Documents/ChatGPT/Логистика — аналитика автопарка'
./start.sh
```

Адрес: http://127.0.0.1:8765 . Сервер привязан только к loopback. Логин и случайный пароль руководителя находятся в `data/local-login.txt` (права 0600). Уже открытая вкладка сохраняет сессию 12 часов. При первом запуске одноразовая ссылка `/bootstrap/<значение data/bootstrap.token>` открывает локальную сессию; после использования токен удаляется. Пароли пользователей хранятся как scrypt-хеши. Секрет сессии хранится отдельно от кода.

Для установки на новом компьютере: Python 3.12+, `python3 -m venv .venv`, `.venv/bin/pip install -r requirements-lock.txt`. Исходный путь книг задаётся в `app/importer.py`; новые версии обеих книг можно загрузить в разделе «Настройки → Импорт Excel». Публикация в сеть и промышленное размещение не выполнялись.


## Интерфейс и обновление 29 октября

[Руководство для заказчика](docs/Руководство-заказчика.md) · [Сверка всех Excel-таблиц и записи заказчика](docs/ui-ux-20261029/EXCEL-REQUIREMENTS.md) · [Результат UI/UX-проверки](docs/ui-ux-20261029/RESULT.md).

- «Данные» содержат заявки, показания спутника, операции обоих топливных поставщиков и справочники. «Подключения» содержат состояние источников и ссылки к данным.
- «Качество данных» разделяет исправимые записи, ограничения API и исторические замечания импорта. Пустые карты, расходы и периоды объясняют, что заполнить и на что это влияет.
- Календарь планировщика переключается между маршрутами и автомобилями. Встроенная инструкция находится в «Помощь → Как пользоваться».
- Работающий `./start.sh` запускает серверный цикл каждые 300 секунд. Автоматически обновляется текущий месяц до сегодняшнего дня по МСК; спутниковая история — последние завершённые сутки. Открытая вкладка для работы цикла не нужна.
- Общая кнопка руководителя получает данные из API за применённый период (1–31 день); наблюдателю и логисту перечитывает рабочую базу. Источник с ошибкой отмечается отдельно. Долгое задание не накладывается на следующее.
- При вводе в форму или открытой карточке обновление экрана откладывается. Поиск, сортировка и прокрутка таблиц сохраняются. Просмотр августа на страницах топлива остаётся августом после автоматического обновления октября.
- Excel автоматически не перечитывается. Фактические привязки карт, полноту периодов и дополнительные расходы должен заполнить ответственный сотрудник; приложение не выдумывает их.

## Возможности

- Статистика по машинам, водителям, их сочетанию, клиентам, типам транспорта, исполнителям, датам и видам начислений; произвольный период; CSV и детализация заявок.
- Календарь автомобилей/водителей: работа и ручные статусы. Статусы не превращаются в заявки.
- Планировщик: реальные маршруты, ставки, назначение на период и дни недели, список и календарь, расчёт выплат своим водителям/партнёрам.
- План–факт по рейсам; отсутствие источника обозначено «—».
- Сверка ТТ–спутник по машине и дате начала, с отсутствующими данными и детализацией.
- Справочники и повторный импорт Excel без умножения строк. Предыдущие снимки сохраняются; ручные записи остаются.
- Роли руководителя, логиста и наблюдателя; машины логиста, журнал действий, серверные проверки доступа и CSRF.
- Диагностика подключений. **Нефтьмагистраль подключена: транзакции загружаются через API по кнопке за выбранный период.** **Роснефть подключена: карты, операции, скидки, возвраты и CSV; обновление по кнопке за период до 31 дня.** **ГЛОНАССсофт подключён: объекты, последние показания и история пробега, моточасов и топлива.** История загружается небольшими суточными порциями с продолжением после прерывания и используется в статистике и сверке. **ТрансТрейд подключён: серверное чтение заявок, обновление по кнопке за период до 31 дня, история изменений и защита от дублей.** Подробности в `docs/Подключения.md`.

## Данные и расчёты

См. `docs/Excel-карта.md` и `docs/Проверка.md`. Важно: книги с разными месяцами; часть выплат без автомобиля; часы/км начислений и штрафов не являются работой рейсов. Денежные строки импортируются целиком, разница доходов и выплат не называется чистой прибылью.

`data/` содержит SQLite, локальные учётные данные, снимки, журнал и состояние проверок. Каталог 0700; не включён в Git. Резервировать весь каталог в закрытое хранилище. `work/` содержит промежуточный аудит и отдельную тестовую базу. Файл доступов не копировался в приложение и не включался в Git.

[Матрица требований](docs/requirements-20261029/MATRIX.md) · [Проверки и сохранность](docs/requirements-20261029/VERIFICATION.md). Полностью перечитана исходная запись, сверены обе книги и изображения. Добавлены детали API-заявок, группировки по неделям и логистам, фильтры календаря/планировщика и корректная обработка отсутствующих показателей.

Обновление: общая кнопка «Обновить данные» либо «Данные → Заявки ТрансТрейд → Обновить заявки за выбранный период». API не передаёт километраж; актуальный пробег ТТ остаётся неизвестным, старый Excel виден отдельно в деталях. API не сообщает часовой пояс, общий счётчик и удаления. Отмены обрабатываются только по явному статусу; исчезнувшие заявки сохраняются с отметкой проверки. Локальные заявки и категории не теряются. Реквизиты — только в закрытом `data/transtrade-credentials.json`; этот файл не включается в Git.

Повторная проверка 29 октября: сентябрь загружен (1088 заявок), 51824 восстановлена точечным запросом. Для этого компьютера `data/transtrade-network.json` задаёт `{"interface":"en0"}`: привязка только запросов ТТ к физическому интерфейсу macOS при сбое маршрута VPN. Если файл отсутствует, используется обычный маршрут; если указанный интерфейс недоступен, обновление прекращается с сохранением прежних данных.
