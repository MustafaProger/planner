# Логистика — аналитика автопарка

Локальное веб-приложение на русском языке. Работает на реальных Excel-данных, не требует облачной публикации. Artel-CRM не используется и не изменяется.

## Запуск

```sh
cd '/Users/mustafa/Documents/ChatGPT/Логистика — аналитика автопарка'
./start.sh
```

Адрес: http://127.0.0.1:8765 . Сервер привязан только к loopback. Логин и случайный пароль руководителя находятся в `data/local-login.txt` (права 0600). Уже открытая вкладка сохраняет сессию 12 часов. При первом запуске одноразовая ссылка `/bootstrap/<значение data/bootstrap.token>` открывает локальную сессию; после использования токен удаляется. Пароли пользователей хранятся как scrypt-хеши. Секрет сессии хранится отдельно от кода.

Для установки на новом компьютере: Python 3.12+, `python3 -m venv .venv`, `.venv/bin/pip install -r requirements-lock.txt`. Исходный путь книг задаётся в `app/importer.py`; новые версии обеих книг можно загрузить в разделе «Источники данных». Публикация в сеть и промышленное размещение не выполнялись.

## Возможности

- Статистика по машинам, водителям, их сочетанию, клиентам, типам транспорта, исполнителям, датам и видам начислений; произвольный период; CSV и детализация заявок.
- Календарь автомобилей/водителей: работа и ручные статусы. Статусы не превращаются в заявки.
- Планировщик: реальные маршруты, ставки, назначение на период и дни недели, список и календарь, расчёт выплат своим водителям/партнёрам.
- План–факт по рейсам; отсутствие источника обозначено «—».
- Сверка ТТ–спутник по машине и дате начала, с отсутствующими данными и детализацией.
- Справочники и повторный импорт Excel без умножения строк. Предыдущие снимки сохраняются; ручные записи остаются.
- Роли руководителя, логиста и наблюдателя; машины логиста, журнал действий, серверные проверки доступа и CSRF.
- Диагностика подключений. **Живые данные провайдеров пока не синхронизируются.** Подробности в `docs/Подключения.md`.

## Данные и расчёты

См. `docs/Excel-карта.md` и `docs/Проверка.md`. Важно: книги с разными месяцами; часть выплат без автомобиля; часы/км начислений и штрафов не являются работой рейсов. Денежные строки импортируются целиком, разница доходов и выплат не называется чистой прибылью.

`data/` содержит SQLite, локальные учётные данные, снимки, журнал и состояние проверок. Каталог 0700; не включён в Git. Резервировать весь каталог в закрытое хранилище. `work/` содержит промежуточный аудит и отдельную тестовую базу. Файл доступов не копировался в приложение и не включался в Git.

## Проверки

```sh
.venv/bin/python -m pytest -q
```

14 автоматических проверок: суммы Excel, спутниковая сводка, расчёты планов, фильтры, отделение начислений от загрузки, повторы, права, CSRF, удаление ручной записи и повторный импорт. Браузерные сценарии проверены отдельно; тестовые деловые записи не создавались у провайдеров.
